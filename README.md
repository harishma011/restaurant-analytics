# Restaurant Analytics Project

**Data Analytics using Excel, Python, MySQL, and Power BI**

## Project Overview

This project analyzes restaurant, customer, cuisine, location, and order data to understand restaurant performance and identify useful business insights. The analysis covers data cleaning, exploratory data analysis, SQL querying, Excel reporting, and interactive Power BI dashboards.

The goal is to transform raw data into meaningful insights that can support business analysis and decision-making.

## Project Objectives

- Analyze restaurant performance across different locations and cuisines.
- Explore restaurant ratings, average costs, and customer-related metrics.
- Examine order data to understand business performance and trends.
- Identify top-performing restaurants, cuisines, and locations.
- Present findings through visualizations and interactive dashboards.

## Tools and Technologies

- **Microsoft Excel:** Data cleaning, PivotTables, formulas, charts, and summary reporting.
- **Python:** Pandas, NumPy, Matplotlib, and Seaborn for data preparation, exploratory data analysis, and visualization.
- **MySQL:** Data querying, filtering, joins, aggregation, and business-question analysis.
- **Power BI:** Data modeling, DAX measures, KPI cards, slicers, interactive reports, and dashboard development.

## Project Workflow

1. **Data Cleaning:** Checked datasets for duplicate records, missing values, inconsistent entries, and data type issues.
2. **Excel Analysis:** Used PivotTables, formulas, and charts to summarize data and explore business metrics.
3. **Python Analysis:** Performed exploratory data analysis and created visualizations to identify patterns and trends.
4. **SQL Analysis:** Wrote MySQL queries to retrieve, filter, group, and summarize data for business questions.
5. **Power BI Reporting:** Developed interactive reports with KPIs, slicers, trend analysis, rating-versus-cost comparisons, and Top 10 analysis.

## Key Areas of Analysis

- Restaurant count and distribution by location.
- Restaurant ratings across different locations.
- Cuisine popularity and restaurant availability.
- Relationship between restaurant ratings and average cost.
- Order value and other available order-related metrics.
- Identification of top-performing restaurants and locations.
